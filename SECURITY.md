# Security policy

Vialix sends the user's position to a routing server and a geocoder (see [PRIVACY.md](PRIVACY.md)),
so anything that leaks a position further than that, or lets a server response do more than draw
a route, is a security issue.

**Please report vulnerabilities privately** through GitHub's
[private vulnerability reporting](https://github.com/igalmarino/vialix/security/advisories/new)
rather than in a public issue. Expect an acknowledgement within a week.

Only the latest release is supported with fixes.
