# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be respectful, assume good faith, keep criticism about the work, and make
room for people who are new to the project or to the field.

Reports of unacceptable behaviour go to the maintainer through GitHub (a private message to
[@igalmarino](https://github.com/igalmarino), or a private security advisory if you prefer that
channel). Reports are handled confidentially.
